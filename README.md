# Air-bnb-Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard built using Airbnb listings and reviews data. The dashboard provides insights into property availability, pricing, customer reviews, room types, and host performance to help understand trends in the Airbnb rental market.

The objective of this project is to transform raw Airbnb data into meaningful business insights through data cleaning, modeling, DAX measures, and interactive visualizations.

---

## 🎯 Objectives

- Analyze Airbnb listings across different locations.
- Understand pricing trends and room type distribution.
- Evaluate customer reviews and ratings.
- Identify top-performing hosts and neighborhoods.
- Create an interactive dashboard for business decision-making.

---

## 📂 Dataset

The project uses Airbnb datasets containing information such as:

- Listings
- Hosts

- Prices
- Availability
